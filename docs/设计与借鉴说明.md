## 一、这轮从三个例子里各拿走了什么

### 1. `setup-my-iq`（GitHub 官方 awesome-copilot）—— 最大的收获，也是最痛的自我批评

它让我意识到 v0.1 有个致命漏洞：**档案躺在 vault 里，AI 每次会话其实不一定读得到。** 那不是"懂我"，那是"家里有本书"。

| 借了什么 | 落在哪 |
|---|---|
| **指针接入机制**：用 `@绝对路径` 把档案挂进宿主指令文件，不绑定任何特定 AI 工具 | `接入与接线.md` + `assets/AGENTS-block.md` |
| **托管块**：`<!-- self-profile:start/end -->`，重跑只换块内，块外一个字节不动（幂等） | 同上 |
| **四态检测**：PRESENT / STUB / REFERENCED-MISSING / NOT REFERENCED | `SKILL.md` 第零节 |
| **预填优先**：问之前先扫已有材料，做成提案标"自动填充"让人确认 | `冷启动访谈.md` 第零步 |
| **一次只问一个问题**，绝不甩清单、绝不问复合问题 | 同上 |
| **反问环节**：起草后让人挑最不像的一句；说"没问题"就推一次，第二次接受 | 同上 第四节 |
| **负面提问**：给一句典型的 AI 腔，问"哪里不像你"——一次挖出三四个避用词 | 同上 第 4 轮 |
| **挫败感引出规则**："上次 AI 做了你不想要的事是什么"，一答常产 3 条边界 | 同上 第 5 轮 |
| **占位符修补**：只问缺的字段，不重跑全量 | `接入与接线.md` 第四节 |
| 改文件前备份 `<file>.bak-时间戳`、绝不删除 | 安全条款 |

**唯一反向改造**：它明确说"我不会自动学习，只在被明确要求更新时进化"。而这套系统的前提是自进化，所以这里把它翻转成了**四环闭环 + 三刹车**——进化必须能回滚、能审计、不过拟合。

### 2. `experience-as-skill` —— 让"懂我"从模仿语气升级到复用方法

| 借了什么 | 落在哪 |
|---|---|
| **"抽结构，不抽传记"**（Extract structure, not biography） | `框架 frameworks.md` 的设计前提 |
| **命名框架六要素**：是什么 / 何时用 / 怎么做 / 出处 / 反模式 / 验证状态 | `frameworks.md` 模板 + `蒸馏细则.md` 月蒸馏 |
| **反模式条目**：表现 → 代价 → 触发条件 → 解药 | `反模式 anti-patterns.md` |
| **深度等级 + "我的深度边界"**：诚实标注哪里不懂，不过度宣称 | `domains/` 模板 |
| **跨源综合的五类模式**：重复主题 / 已命名框架 / 领域聚类 / 声音签名 / 转折点 | `维度与证据.md` + `冷启动访谈.md` |
| **Token 预算 + 按需加载 + 双层索引**：主文件前置最重要内容，域文件读了才占预算 | `SKILL.md` 三层消费结构 |
| **作用域声明**：档案只反映到某个日期，域外说"不知道" | `me.md` 与 `框架` 的头部字段 |
| **冲突必须当面提出**，因为它影响框架怎么用 | 冲突队列 |

它的短板恰好是我们的强项：**它没有自进化**（只有手动重跑）。所以这套系统在它停下的地方接着走。

### 3. `yourself-skill` —— 自进化必须有刹车，人格必须有棱角

| 借了什么 | 落在哪 |
|---|---|
| **Correction 层**：说"我不会这样说"→ 立即生效，不等复盘 | `纠正日志` + 秒级纠正通道 |
| **版本管理 + 回滚**：每次更新存档，可回滚 | `.history/` + `回滚` 命令 |
| **Persona 五层**：硬规则 → 身份 → 说话风格 → 情感模式 → 人际行为 | `分身 persona.md` |
| **层 0 硬规则里最关键的一条**："保留棱角，不完美才真实" | persona 层 0 |
| **标签只做入口不做结论**：MBTI/星座/性格标签必须翻译成可观察的行为规则 | `维度与证据.md` 反夸大条款 |
| **三种调用模式**：完整 / 档案模式 / 人格模式 | `像你` / `查档案` / `校准` |
| **原材料优先级**：深夜独白 > 情绪波动 > 做决定的聊天 > 日常闲扯 | `冷启动访谈.md` 首月清单 |
| **诚实的结尾**："你并非一个固定的人格，而是一连串正在发生的选择" | 整份系统的态度 |

## 二、v0.1 → v0.2 六处升级

| # | 升级 | 为什么必须做 |
|---|---|---|
| 1 | **接线层**（指针 + 托管块 + 四态自检） | 不解决这个，前面全部白做 |
| 2 | **三层消费结构**（常驻 ≤400 token / 按需 / 证据） | 全量塞上下文＝更不懂你，模型会淹没在细节里 |
| 3 | **四个产出面**（懂我 / 怎么说 / 怎么做 / 扮演我） | v0.1 只有"是什么"，没有"怎么用" |
| 4 | **十二个维度 + 覆盖度指标** | 防止档案只记得住你的工作，记不住你的生活 |
| 5 | **自进化四环 + 三刹车 + 四指标** | 你要的自进化；没有刹车的自进化是自毁 |
| 6 | **纠正秒通道 + 版本快照** | v0.1 只能等周蒸馏，太慢，用户早就放弃了 |

## 三、三个核心判断（v0.2 版）

### 1. 行为 > 自述，并把裂缝当资产
证据表第一原则是行为投票。声明自我与行为自我冲突时，**不化解**，而是单独记进 `分析/自我认知偏差.md`——"我以为的我"和"实际的我"之间的距离，才是自我认知真正的位置。

### 2. 自进化 ≠ 自动改写
四环里只有"纠正"和"捕获"是秒级的，升级永远要人签字。三条刹车是硬约束：
**可回滚、可审计、过拟合暂停（连续 3 次同向纠正就停手）。**

### 3. 张力数 0 是警报，不是成绩
健康指标里 `张力数` 的健康区间是 **1–3**。降到 0，说明档案在自我美化；涨到 5 以上，说明判据太松。真人的档案里一定有互相拉扯的东西。

## 四、怎么用

### 装（3 步）

1. **档案库**：把 `01 搭建规格.md` 交给 AI，在你的空文件夹里现场生成整套目录。
2. **技能**：`03 技能包/self-distill/` → `~/.workbuddy/skills/`（或 `~/.codex/skills/`、`<vault>/.claude/skills/`）。
3. **接线**：说「接线」，把 `me.md` 指针写进 `<vault>/AGENTS.md` 的托管块。**这一步别跳。**

### 日常循环

```
开场      AI 自检三态，没读到就提示接线
每天      「记一下」→ 1 条 L1
随时      「纠正」「我不会这样说」→ 秒级改 + 快照 + 审计
每周日    「周蒸馏」→ L2 候选表 → 你点头
每月底    「月蒸馏」→ L3 + 框架 + 衰减 + 指标
每季度    「季蒸馏」→ L4 候选（你手抄）+ 重生成四个产出面
每两周    「体检」→ 美化检测 / 配音检测 / 单源检测 / 沉默检测
随时      「查档案 X」带证据回答 ｜「像你」切分身 ｜「回滚 日期」
```

### 现实预期

| 阶段 | 现实 |
|---|---|
| 第 1 周 | 档案空，说明书基本是你口述的。正常。 |
| 第 1 月 | 8–15 条 L1、3–5 条 L2、0–1 条 L3，覆盖 3–4 个维度。还不好用。 |
| 第 3 月 | 出现第一次"这条我不同意"——**系统开始工作了**。 |
| 第 6 月 | 说明书能直接当系统提示词；框架开始真正省你时间。 |
| 第 1 年 | L4 也许只改 2 条。那 2 条比前面所有条目加起来值钱。 |

## 五、它会怎么死（v0.2 的解药）

| 死法 | 症状 | 解药 |
|---|---|---|
| **没接线** | AI 每次都像第一次见你 | 开场四态自检 + `接线` 命令 |
| **采集过载** | 什么都想记，一周后放弃 | 一天 3–8 条上限 |
| **AI 自画像** | 越读越像"一个温和理性的人" | L4 只读 + 升级签字 + 美化检测 |
| **过拟合** | 某次情绪后档案把你写成另一个人 | 三次规则 + 回滚 |
| **上下文淹死** | 塞太多，AI 反而抓不住重点 | 三层结构 + token 预算 |
| **偏科** | 只懂工作不懂生活 | 覆盖度指标 + 下月优先补 2 个维度 |
| **僵尸档案** | 攒了 200 条，从没打开过 | 说明书每周至少用一次 |
| **语言失真** | 读起来像 AI 写的总结 | 配音检测 + 每条保留原话 |

## 六、v0.3 增补：导入式建档

**首次使用不该先答题。** 手上已有简历、日记、项目文档、聊天记录的人，应该被"读一遍"，而不是被"问十五遍"。

| 变化 | 内容 |
|---|---|
| 新增路径 | `references/导入式建档.md`——八步：材料清单 → 分级 → 逐源抽取 → 冲突暴露 → 起草带豁口的档案 → 缺口矩阵 → 只问空白 → 落笔接线 |
| 新增命令 | `导入建档`；`初始化档案` 改为自动分流（有材料→导入，无材料→访谈）。命令数 12 → 13 |
| 认识论前提 | **简历是自述（T4），不是行为证据（T2）**。简历不产 L2；须获得 1 次真实决策支持才转正 |
| 材料分工 | 每类材料只给它"只有它能给"的东西。只有简历时，**声音与 L2 一律不生成** |
| 安全剔除 | 联系方式、身份证、住址、薪资明细、紧急联系人：一律不入档、不进摘要页 |
| 顺带修复 | 补回**摄入流程**（`raw/` → `sources/` 摘要 → `已摄入/`），与导入共用同一套证据规则 |

一次导入的典型产出：`me.md` 七成、时间线九成、`domains/` 一到三个、声音五成、L2 候选三到五条（全部待验证）。
**框架层通常为空**——框架只能从反复的做法里长出来，不能从简历里读出来。

## 七、v0.4 收尾修复

### 结构类

| 项 | 修法 | 为什么 |
|---|---|---|
| **`me.md` 的「现在」会过期** | 拆出 `当前 current.md`（唯一手改区，周级更新），`me.md` 只放指针 | `me.md` 每月重生成，而"现在在忙什么"是周级变化。写进去等于立刻过期 |
| **维度表双维护** | 只在 `健康 health.md` 维护，目录里改成链接 | 同一份数据抄两遍，三个月后一定对不上 |
| **双副本漂移** | 新增 `VERSION` 文件（含 changelog）+ 明确"单一真源" | 见 `references/升级与同步.md` 第七节 |
| **空目录丢失** | 各目录加 `.gitkeep`（空文件） | 云同步/压缩时目录会丢，`me.md` 的链接就断了 |
| **时间线无枚举** | 固定七类：职业/项目/关系/健康/迁移/学习/决策 | 类型自由填写＝无法统计 |
| **L3 缺证据等级** | 补 `证据等级` 字段，取支撑 L2 的最高级 | 没有等级就无法与 L2 比较可信度 |
| **命名不统一** | **不改名**，改为写明理由 | `me.md` 要被宿主用 `@绝对路径` 引用；路径含空格或中文时，部分宿主解析 `@` 指针会失败。这是唯一有意保留的英文名 |

### 能力类

**1. 速查 10 条**
AGENTS 顶部加一个「平时只看这 10 条」。全文仍保留细则——**但第一屏必须是能背下来的十条**。
原先想做"压缩到 1500 字"，放弃：那会真的删掉规则。**加一个入口比砍掉内容更划算。**

**2. 命中 / 落空（结果反馈）**
`L2` / `L3` 各加 `命中`、`落空` 两个计数。纠正与捕获是**入场时**的反馈，这一环是**出场后**的反馈——这条判断后来应验了吗。
- `命中率 = 命中 / (命中+落空)`，样本 <3 不显示——太少时比例没有意义。
- 命中率 ≥0.8 且样本 ≥5 → 月蒸馏 +0.05；<0.4 → 降 `待观察`，体检专审。
- **哪一类判断命中率系统性偏低，就是你最不了解自己的地方**——比任何自述都准。
- AI 不得自己判定"应验了"，那是自我打分。

**3. 十分钟最小路径**
无材料时，只问三句（靠什么吃饭 / 只能保住什么 / 怎么跟你说话），产 `me.md` v0.0.1。
必须说这句实话："**这版只有三成，剩下七成靠以后慢慢长。**"
先让人觉得"它懂我一点"，再谈蒸馏——否则第一次体验是六个问题的问卷。

## 八、v0.5–0.6：数字化（底卡 + 经历）

日常捕获有个天然盲区：**它只能采到"最近发生的事"。**
童年、转学、第一次离开、最难的那一年——永远不会被捕获，因为它们不新鲜。

但这里我第一版做错了：把它做成了「传记」。**传记是文学体裁，不是数据。** 用户要的是"把我数字化"——结构化、可检索、能持续增补的一份"我"。

修正后是两层：

| 层 | 文件 | 放什么 |
|---|---|---|
| **底卡** | `档案 profile/数字档案 identity.md` | 客观事实：基本信息、家庭、教育、职业、居住轨迹、健康、偏好雷区、重要他人、技能概览 |
| **经历** | `档案 profile/经历 experiences.md` | 五种条目：**事件 / 场所 / 物件 / 感官 / 相遇** |

`references/经历挖掘.md` 提供十一问，按阶段推进，一次一个；建议 20–40 条。

**为什么加"场所 / 物件 / 感官"**：它们不解释任何事，但一碰到就回到某个年纪。
一个只记得你"哪年换工作"的 AI，记住的是简历；一个记得你"闻到雨后水泥地会想起小学"的 AI，才像认识你。

### 核心原则：回忆不是证据

记忆会被重写。你今天讲的童年，和十年前讲的可能不是同一件事——而两个版本你都会觉得千真万确。

所以每条必标**记忆类型**：

| 类型 | 等级 | 用途 |
|---|---|---|
| 亲历 | T4 | 可作 L4 候选背景，**不作行为证据** |
| 转述 | T6 | 只能作佐证 |
| 模糊 | 不参与 | 只记录，不进结论 |
| 有佐证 | T2–T3 | 唯一能当硬证据的回忆 |

### 三条硬规矩

1. **经历不产 L1 / L2。** 把童年事件写进 L2 是最典型的层级污染——经历是背景，不是行为模式。
2. **旧条目只增不改。** 记忆变了就另起一条「修订」，不覆盖原文。"我去年是这么记得的"本身是数据。
3. **R 级例外。** 用户手写的经历条目可标 R 留档（那是他自己的记忆），但不得被 me / 说明书 / 声音 / 框架 / 分身引用，也不参与 L3/L4 提炼。

### 它和已有的东西怎么分工

```
底卡（客观事实，稳定）
经历（长期，事件 + 场所 + 物件 + 感官）
  ├─→ 时间线（短，只挑改变轨迹的，7 类枚举）
  ├─→ L3 候选（反复出现的主题，≥3 条证据 + 你确认）
  ├─→ L4 候选（你为此放弃过什么）
  └─→ domains/（某个领域的深度从哪来）
```

**经历是源，时间线是索引。** 两处都写详细内容＝两处都会错。

## 九、v0.7：把记录塞进聊天里

之前所有捕获都靠一句「记一下」——**入口太重**。人不会为了被记录而专门说一句指令，聊着聊着就忘了。

改成三种入口，默认全开：

| 入口 | 谁发起 | 频率 | 打断感 |
|---|---|---|---|
| 自动捕获 | AI | 每次对话 | 无（末尾一行回执） |
| 会话内提问 | AI | ≤1 次 / 会话 | 低 |
| 定时提问 | 定时任务 | 每天或每周 | 中（可关） |

### 自动捕获只记五类

决策+理由 / 情绪+触发点 / 明确偏好 / 鲜明立场 / 本想 X 做了 Y。

**不记**：事务协作、信息查询、AI 的话、公开知识、纯计划、转述他人。

回执**一次会话只汇总一行**：`记了 2 条：决策方式 · 情绪地形（说"撤销"可删）`。
每条都报，等于让人不敢随便说话。

### 主动提问的关键不是"问"，是"别问"

| 什么时候不问 | 为什么 |
|---|---|
| 你在赶时间 / 解决具体问题 | 问题会被当成干扰 |
| 你情绪低落 | **这时只陪不问**，记录等之后 |
| 本会话已问过 1 个 | 一次会话一个问题，是上限不是平均值 |
| 你 7 天内跳过过同类 | 跳过就是明确信号 |

**打扰预算**：跳过 → 7 天不问同类；连续 3 次跳过 → 停 30 天；「暂停」→ 全停。

### 三条边界

1. **不把聊天变成问卷。** 连续两次没接话，就此打住。
2. **不在难受时提问。** 情绪低谷只做一件事：听。
3. **不为了记录制造话题。** 没有问题就不问——空白比打扰便宜。

问题库按三个粒度分层：每日（10 秒能答，按 12 维度轮转）、每周（需想一下）、每月（适合安静的时候）。

## 十、一句话

这套东西最终要回答的不是"我是谁"，而是——

**在什么条件下，我会做出什么选择；以及我凭什么相信这个判断。**

前者是简历，后者才是能拿来用的东西。
