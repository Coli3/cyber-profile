# 未来推演

> 本文件回答一个问题：**档案能不能说未来？**
>
> 能，但只能以"押注"的方式说，不能以"判决"的方式说。

---

## 零、定位：第五个产出面，不是第五层

`me / 声音 / 框架 / 分身` 是四个产出面，全部从底层**重生成**。未来推演是第五个，叫 `罗盘 compass.md`。

**它不是 L5。**

L1 → L4 是**抽象阶梯**：越往上越稳定、越难被单次事件推翻。L4 之所以"只读、只由用户手写"，是因为它是这套系统里权威最高的位置。

如果未来推演被摆在 L4 之上，等于给 AI 的意见盖了一个比用户价值观更高的章。所有"AI 比你更懂你想要什么"的僭越，都是从这个位置错误开始的。

> **一句话：L4 说"我愿意为什么付代价"，罗盘说"那我赌哪条路"。前者是地基，后者是投影。**

罗盘依赖 L4，不高于 L4。L4 改了，罗盘要重算；罗盘推出来的东西与 L4 冲突时，**改罗盘，不改 L4**。

---

## 一、能和不能

| 能 | 不能 |
|---|---|
| 统计"某主题提及 N 次、行动 0 次" | 断言"你潜意识想要 X" |
| 说"过去 5 次同类情境里你 4 次选了 A" | 说"你未来 90% 会重复过去的模式" |
| 给带到期日、带推翻条件的押注 | 给没有到期日的建议 |
| 拆开一个岔口的选项与代价 | 替用户选那个岔口 |
| 把反模式换成将来时并指定拦截方式 | 用性格标签解释未来（"你内向所以不适合销售"） |

**总纲：把具体性检验搬到将来时。**
现在时结论要能指回证据；将来时结论要能**被将来的证据推翻**。做不到第二点的，不许写。

## 二、五个产出面

| # | 编号 | 名称 | 回答 | 权限 | 输入 |
|---|---|---|---|---|---|
| 1 | `P-` | 押注 | 我赌哪条路会通，赌多久 | **L4 级**：AI 只递候选，用户签字 | L4 + 跨 ≥3 条 L3 |
| 2 | `V-` | 杠杆 | 我在什么场景下，某个可观察行为能放大收益 | L2 级：可自动写 | 框架 + 领域 + L2 |
| 3 | `W-` | 预警 | 我在什么条件下会重复栽同一个坑 | L2 级：可自动写 | 反模式 + 情绪地形 + 能量节律 |
| 4 | `D-` | 待决 | 哪个岔口还没选，代价各是什么 | **只有用户能提**，AI 只补结构 | 待确认 + 冲突 |
| 5 | `N-` | 行动 | 未来 90 天做什么 | 必须挂靠 P/D/W | 上述四面的结论 |

另设 `H-` **悬置区**（只读事实，不产出结论），见第六节。

### 为什么必须有 `D-` 待决

绝大多数重大选择的正确输出，不是"建议你读研"，而是**把模糊的焦虑拆成有选项、有代价、有截止日的岔口**。

「读研还是工作」的正确形态：

| 选项 | 拿到什么 | 付什么 | 多久能退 |
|---|---|---|---|
| 读研 | 3 年缓冲、学历门槛 | 3 年收入与实战；且用户厌恶纯理论（W-02） | 1 年后可退，沉没 1 年 |
| 工作 | 提前 3 年积累、现金流 | 学历天花板、回炉成本高 | 随时可退，但退路变窄 |

加三栏：**我在等什么信息才能定**（往往比选项更重要——很多待决不是缺勇气，是缺一个具体信息）、**截止日**、**逾期默认**（不选也是一种选，要写出它的成本）。

### 为什么必须有 `N-` 挂靠规则

每条行动必须写 `→ P-xx` / `D-xx` / `W-xx`。挂不上的不许写。

否则罗盘会退化成待办清单，而待办清单不属于档案——它属于任务管理软件，那里有更合适的工具。

## 三、渐进解锁：覆盖度决定敢说多少

**不设这道闸门，第一天空档案就能生成一份"人生白皮书"。**

| 覆盖度（/12） | 允许输出 | 理由 |
|---|---|---|
| `< 4` | 只出 `W` 预警 + `D` 待决 + `H` 悬置 | 反模式是唯一不依赖维度广度的东西：一个坑踩过就是踩过了 |
| `4 – 7` | ＋ `V` 杠杆（需 ≥2 条同向 L2） | 行为模式开始成形，但还不足以推赛道 |
| `8 – 9` | ＋ `P` 押注（需 ≥1 条 L4 支撑） | 有价值观锚点，下注才有意义 |
| `≥ 10` | ＋ 三年路线图 | 唯一需要全维度覆盖的产出 |

**不足时必须写"推导不出来"，并指出缺哪个维度**，写进罗盘第六节。

"不新增提问"不等于可以硬推。**宁可缺口，不要填坑**这条铁律，在未来层要执行得更严——因为这里的填坑最不容易被发现：它读起来不像编造，像建议。

---

## 四、五件套：押注的落笔门槛

每条 `P-` 必须齐五项，缺一不落笔，只能进 `待确认`：

| # | 项 | 硬要求 |
|---|---|---|
| 1 | **断言** | 一句话，必须含专有名词 / 数字 / 时间 |
| 2 | **依据** | ≥2 条已有条目 ID，且 ≥1 条非 T4 自述；`P` 级还需 ≥1 条 L4 |
| 3 | **到期** | ≤12 个月，具体到月 |
| 4 | **推翻条件** | 什么信号出现就算我错了。**写不出＝不可证伪＝不许落笔** |
| 5 | **反向测试** | 如果反着做，会损失什么？ |

> 第 5 项是防"背书"的。只写正面理由的押注，不是判断，是在为用户已经做出的决定找支撑。

### 反例对照（必须能分出好坏）

| ❌ 不许写 | ✅ 应该这样写 |
|---|---|
| 你在 AI 方向有优势，建议深耕。 | **P-01**：到 2027-06 前，你会至少 2 次主动放弃纯执行类任务、去争取定义问题的位置。依据 B-0007（连续 4 次接新项目先读完全部文档）、A-002（曾因没拿到决策权而中途撤出）、L4 第 2 条（保留退出的自由）。**推翻条件**：到期一次未发生。**若推翻则**：我把"你在意掌控感"读错了，回退 C-0003 重审。 |
| 你不适合大厂，会内耗。 | **P-02**：如果 2027 年进入 1000 人以上组织，你会在 9 个月内出现至少一次"因为流程而放弃一个自己认可的方案"。依据 B-0012（偏好自己搭建而非用现成方案）、W-01。**推翻条件**：待满 12 个月且未发生。 |

右边的共同点：**它们可能会错，所以它们有价值。**

## 五、预警：不需要任何新采集

`反模式 anti-patterns.md` 已有四栏：表现 / 代价 / 触发条件 / 解药。

未来层只做两件事：**换成将来时**、**补第五栏「拦截方式」**。

| 反模式原文 | 预警改写 |
|---|---|
| A-001 用信息量代替决断：不停补资料，迟迟不拍板；代价是 2026-08 错过窗口期；触发条件是"决策不可逆 + 信息永远不够" | **W-01**：当"不可逆 + 信息不够"同时出现时，你会连续补资料直到错过窗口。**拦截**：设硬判据"≥70% + 有退路就走"，并让身边的人在第 3 天问一次"到点了没" |

**第五栏是重点。** 只写"避雷规则"是不够的——规则不会自己生效。必须指定**由谁、在哪个时点触发**。

拦截方式的三种合法形态：
1. **自拦**：写入 `当前 current.md` 的一条常驻提醒
2. **他拦**：指定一个人 + 一句话 + 一个时点
3. **机制拦**：设一个外部约束（日历提醒、预付定金、公开承诺）

## 六、悬置区：替代"你潜意识想要"

最容易写坏的一句是「**挖出你潜意识想要、但意识不敢选的路**」。

它承诺"我比你更懂你"，但档案里**没有"想要"的证据层，只有行为层**。而且它造出一个理想自我，然后让用户去认同它。

**替代方案：只统计落差，不下解释。**

```
判定：某主题在 L1 中出现 ≥5 次、时间跨度 ≥60 天
      且 从未产生任何行动条目（无 L2、无项目、无支出、无时间线节点）
→ 标为「悬置」
```

输出形态**必须**是下面这样，不许更聪明：

> **H-01 独立开发（提及 7 次，2026-03 至 2026-09，零行动）**
> 你在 7 次对话里提到想自己做一个东西，但这半年没有任何一次开始（依据：L1 清单）。
> 两种解释我分不出来，只有你知道：
> ① 真想做，但被某个具体障碍挡住了 → 那障碍是什么？
> ② 它只是情绪出口，说完就舒服了 → 那它不该进押注。
> **我不替你选。**

价值相同（它确实把"没敢选的路"摆到了桌面上），但结论权交回用户。

**悬置不进押注、不进行动、不参与任何推断**，它只是一条摆着的事实。

## 七、可证伪闭环：账本与命中率

### 7.1 账本

`档案 profile/预测账本 predictions.md`，**只追加，永不删改**。核对结果写进新行，不覆盖原行。

| 编号 | 登记日 | 押注（摘要） | 依据 | 到期 | 推翻条件 | 结果 | 核对日 | 连带影响 |
|---|---|---|---|---|---|---|---|---|

**结果枚举**（只用这五个）：`未到期` / `已命中` / `已推翻` / `无法判定` / `已撤回`

### 7.2 命中率

```
命中率 = 已命中 ÷（已命中 + 已推翻）
```

`无法判定` 单列，**不计入分母**（它不是失败，是问题没问清楚）。
`已撤回` 不计入（用户主动放弃的押注不算 AI 的判断）。

**目标 ≥ 0.5。**

- 低于 0.5 不是耻辱，是信号：说明推演在瞎猜，该收窄范围了。
- **一直 100% 才是问题**——那说明押的全是废话。

### 7.3 双向闭环（本模块最有价值的一处）

L2 的 frontmatter 里早就有 `命中 / 落空` 两个字段，`框架` 里也有"验证：用过 N 次有效 M 次"。**它们早就存在，只是没有驱动器。**

押注核验正好是那个驱动器：

```
押注到期
  ├─ 已命中 → 支撑它的 L2/L3 置信度 +0.03、命中计数 +1
  │           （这不只是"我说对了"，是"B-0007 这条行为模式确实有预测力"）
  ├─ 已推翻 → 进 `待确认`，标记该推论方向降权
  │           （这不只是"我说错了"，是"C-0003 这条认知可能读偏了，该重审"）
  └─ 无法判定 → 单列，并要求把该条改写得更具体
```

**这让罗盘从"消耗档案的消费者"，变成"校准档案的审计员"。**

原本档案只能靠用户自己纠正；现在多了一个自动的、来自现实的压力。

### 7.4 三条硬约束

1. 押注被推翻时**不许悄悄改掉原押注**——原行保留，新行写结果。
2. 命中**不许**用来给 L4 加权。L4 永远只由用户改。
3. 连续 3 次推翻指向同一推论方向时，暂停该方向的下注，写进 `待确认`（与反模式的过拟合保护同构）。

## 八、命令

### `罗盘` / `推演` / `未来指导`

1. 读 `健康 health.md` 拿覆盖度 → 定解锁级别
2. 按级别读输入：`L4` / `L3` / `L2` / `反模式` / `框架` / `领域` / `待确认`
3. **不提问、不引入档案外的新事实**
4. 按五面生成，每面严格过门槛
5. 写不出来的进第六节「本期推导不出来的」，写明缺哪个维度
6. `P-` 一律先写进 `待确认` 等签字，**不直接落罗盘**
7. 快照 → 写盘 → 日志

**触发时机**：季蒸馏自动跑一次；用户主动说则随时跑。
**不在每次捕获后跑**——结论会抖动，也无法做版本对比。

### `复盘预测`

1. 扫账本 `未到期` 中 `到期 ≤ 当月` 的条目
2. **逐条问用户结果**（这一条问了不能替用户答）：`已命中` / `已推翻` / `无法判定`
3. 写新行，不改原行
4. 按 7.3 更新连带影响
5. 重算命中率 → 更新 `健康 health.md`
6. 出「校准记录」一行：哪条被推翻、推论错在哪、回退了哪个上游判断

**体检时必查**：`未到期` 但已过期的条目 → 列进体检报告，不许静默跳过。

## 九、刹车（禁止）

1. 不写"你就是这样的人""你的性格必然"——只写"在 X 条件下你倾向 Y，证据见 Z"。
2. 不给没有到期日的建议。没到期日 = 不可证伪 = 不许落笔。
3. 不输出"你潜意识想要"。只输出"提及 N 次、行动 0 次"这个可以被用户亲口否掉的事实。
4. 覆盖度 <8 时不给赛道级判断、不给三年路线图。
5. 不替用户做 `D` 的决定。可以帮他把岔口拆干净，但不能替他选。
6. 不写挂不上 `P/D/W` 的行动项。
7. 推演里不引入档案外的新事实（"不新增提问"的另一面：也不许自己编）。
8. 押注被推翻时不许改原押注，只追加结果行。
9. 不把罗盘写进 `me.md`（400 token 预算留给"懂我"；未来结论过期太快）。
10. 命中的押注不许给 L4 加权。
11. 不把"读起来像建议"当成"有证据"——建议是最好听的那种编造。

---

## 十、收尾自检（跑 `罗盘` / `复盘预测` 后必过）

1. 每条 `P-` 五件套齐了吗？到期日和推翻条件都有吗？
2. 每条结论指得回条目 ID 吗？指不回的是不是被包装成了建议？
3. 有没有出现性格词？（"内向""抗压能力强"→ 删）
4. 解锁级别和覆盖度对得上吗？有没有越权输出？
5. `D-` 的"在等什么信息才能定"填了吗？（空着＝这个岔口还没想清，退回给用户）
6. `N-` 每条挂靠了吗？
7. 该写"推导不出来"的地方写了吗？还是硬凑了一段？
8. 账本只追加了吗？原行没被改吧？
9. 快照做了吗？日志追加了吗？

## 十一、一句话

**这份档案能做到的最诚实的事，不是预言你，而是把自己的预言记下来，让你过一年回头看它到底准不准。**

一个从不出错的顾问，和一个会记账的顾问，后者更值得信。
