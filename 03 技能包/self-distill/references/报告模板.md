# 报告模板

> 报告不是为了留档，是为了**下一期能和这一期做差**。
>
> 所以七种报告共用同一个开头：`本期截面`。数字对不上，后面的叙述都是抒情。

---

## 零、命名与位置

`报告 reports/YYYY-MM-DD <类型>.md`

类型只有这八种：`初始化报告` / `导入报告` / `周蒸馏报告` / `月蒸馏报告` / `季蒸馏报告` / `体检报告` / `批量摄入报告` / `未来推演报告`。

**同类报告必须同名式**。文件名是索引，不是创作。

**所有报告共用同一个头**（下方各节不再重复写 frontmatter）：

```yaml
---
type: 报告
date: YYYY-MM-DD
类型: 初始化 / 导入 / 周蒸馏 / 月蒸馏 / 季蒸馏 / 体检 / 批量摄入 / 未来推演
tags: [报告]        # 导入与批量摄入用 [摄入报告]；体检用 [体检报告]；未来推演用 [报告, 罗盘]
---
```

## 一、本期截面（所有报告必填，放在最前面）

```markdown
## 本期截面

| 指标 | 上期 | 本期 | 变化 |
|---|---|---|---|
| L1 条目 | 0 | 42 | +42 |
| L2 行为 | 0 | 9 | +9 |
| L3 认知 | 0 | 2 | +2 |
| 框架 | 0 | 3 | +3 |
| 反模式 | 0 | 1 | +1 |
| 自我评价待核 | 0 | 6 | +6 |
| 待核已证实 / 已证伪 | — | 2 / 1 | — |
| 覆盖度（/12） | 0 | 5 | +5 |
| 准确率 | — | 0.8 | — |
| 新鲜度 | — | 12% | — |
| 张力数 | 0 | 2 | +2 |
| **预测命中率** | — | 0.50 | — |
| **押注 / 已到期** | 0 / 0 | 2 / 1 | +2 / +1 |
| **待决 / 逾期待决** | 0 / 0 | 1 / 0 | +1 / — |
| **解锁级别** | — | 杠杆＋押注 | ↑ |

> 上期数据来源：上一份同类报告的「本期截面」。首次报告填 `—`。
```

**这个块是季度对照唯一的依据。** 没有它，"你变了什么"只能靠回忆，而回忆一定会骗人。

## 二、初始化报告

```markdown
# 初始化报告

## 本期截面
（见通用块）

## 建了什么
| 文件 | 版本 | 依据 |
|---|---|---|
| me.md | v0.1 | 访谈 12 问 |
| 时间线 | v0.1 | 简历 |
| L2 | 3 条 | 第 2 轮取舍问答 |
| 自我评价待核 | 6 条 | 简历与自述 |
| 声音 | 未生成 | 无日记/聊天材料 |
| 框架 | 未生成 | 需反复行为 |

## L4 现状
- 已填：N 条（用户手写）
- 待填：身份 / 长期方向 / 明确不做
- 我不代笔，只提供模板

## 已知空白
| 维度 | 为什么空 |
|---|---|
| 能量节律 | 无材料，也未问到 |

## 需要你确认（≤3 条）
1. 时间线冲突：简历写 2025-06 离职，日记 2025-09 仍在提 —— 哪个准？
2. 待核队列 6 条，哪几条你觉得"其实已经很明显了"？

## 下期观察
- 拒绝的方式
- 拖延的具体对象
- 关系的能量收支

## 自检
- [ ] 文件都在已存在目录
- [ ] L4 未被 AI 写入
- [ ] 接线已完成
- [ ] 日志已追加
```

## 三、导入报告

```markdown
# 导入报告

## 本期截面

## 读了什么
| 文件 | 类型 | 词数 | 抽取等级 |
|---|---|---|---|
| 简历2026.pdf | 简历 | 1,200 | T4（自述） |
| 2024日记.md | 日记 | 8,400 | T2 |

## 建了什么
（me / 时间线 / domains / 自我评价待核 / 声音 / 框架 —— 逐项标"生成 / 未生成 + 原因"）

## 缺口
十二维度：已有 N / 薄弱 N / 空白 N；本次补问 N 个，余 M 个留待日常捕获。

## 剔除与跳过
- 联系方式、身份证、薪资：按安全条款剔除
- 家庭信息：密级 R，未记录

## 需要你确认（≤3 条）
1. 简历与日记的时间线冲突：___

## 下期观察
```

（一句话）

**三条专属纪律**

1. **押注必须签字才落罗盘。** 报告里列出待签项，签字后才写进 `罗盘 compass.md`。
2. **核对结果必须由用户回答**，AI 不得代判。报告只负责把问题问清楚。
3. **命中率必须出现在「本期截面」**——它是这份报告唯一能和上一份做差的硬数字。

---

## 十、写作纪律（六条）

1. **先数字后叙述。** 没有截面的报告等于没写。
2. **「需要你确认」不超过 3 条**，必须编号——让人能回"1 不改，2 改"。
3. **被拒列表必留。** 那是校准 AI 判断力唯一的反馈信号。
4. **不写自我评价。** "本次蒸馏质量较高"是废话；写"3 条候选被拒，理由：证据只有 T6"。
5. **修不了的必须写原因**，不许省略——省略就是假装做完了。
6. **每份报告结尾必须有一句话**："下期最该看的一件事。"

---

## 十一、一句话

**报告的长度应该随信息量变化，但骨架不能变。**
骨架一变，你就再也比不出自己三个月前和现在差在哪里了。

至于未来——**一份敢把自己的预测写下来、并且到期逐条核对的报告，比一百条听起来很准的建议值钱。**
