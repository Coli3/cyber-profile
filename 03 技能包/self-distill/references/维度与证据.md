# 维度与证据

两件事：**记哪些面**（十二维度），**凭什么记**（七级证据）。

---

## 一、十二个维度

每个维度给出：核心问题、什么算证据、常见误判。
**误判栏是重点——大多数"懂你"的失败，都是把弱信号当成了结论。**

### 1. 决策方式
- **问**：信息不足时你怎么拍板？快还是慢？先算还是先试？
- **证据**：真实决策 + 事后复盘的原话（T2）；同类决策重复出现（T1）
- **误判**：把"想清楚了"当成"想得慢"；把一次犹豫当成优柔寡断

### 2. 信息习惯
- **问**：先搜、先问人，还是先自己想？信谁？怎么验证？
- **证据**：观察你实际怎么获取信息（翻了什么、问了谁）；对信息源的偏好表述
- **误判**：把"说要多读书"当成爱读书（T6）；把职业需要当成个人偏好

### 3. 能量节律
- **问**：什么给你劲？什么抽干你？什么时候最有产出？
- **证据**：时间戳分布（深夜/清晨的活跃度）；事后描述"做完很累/很爽"
- **误判**：把"应该休息"当成"需要休息"；把短期疲惫当长期规律（需跨 ≥3 周）

### 4. 语言签名
- **问**：你怎么开场、怎么收尾、怎么表达不满、幽默是什么类型？
- **证据**：原话本身（这是唯一一个原话即证据的维度）；标点与语气词频率
- **误判**：把书面写作风格当成口语风格；把某个场合的正式度当日常

### 5. 工作方式
- **问**：推进节奏？完成标准？一个人干还是边聊边干？
- **证据**：项目推进记录、交付前的行为（改几轮、什么时候停）
- **误判**：把"计划狂"当"自律"；把一次赶工当工作习惯

### 6. 关系模式
- **问**：怎么亲近一个人？边界在哪？冲突怎么处理？
- **证据**：与具体人物的互动记录（注意密级）；对关系的主动投入（T1）
- **误判**：把"社恐自述"当行为事实；把对某一个人的方式当通用模式

### 7. 情绪地形
- **问**：什么触发你？怎么恢复？压抑时是什么样子？
- **证据**：情绪出现的具体场景 + 后续行为（T5 + T1/T2 落点）
- **误判**：**情绪不能单独成页**；把"说了很生气"当成"经常生气"

### 8. 价值排序
- **问**：冲突时牺牲什么保什么？
- **证据**：真实取舍（放弃了什么换来了什么，T1/T2）——这是唯一可靠的方式
- **误判**：把声称的价值观当排序；把"重视家庭"这种人人都说的话当特征
- **判据**：**说不出"为此放弃了什么"的价值观，一律不进 L3。**

### 9. 审美偏好
- **问**：什么质感让你舒服？什么让你立刻反感？
- **证据**：具体的选择与拒绝（选了哪个、否了哪个、原话怎么评价）
- **误判**：把"流行"当偏好；把一次尝试当审美

### 10. 学习方式
- **问**：怎么学会新东西？什么学不进去？需要例子还是需要框架？
- **证据**：学习过程的记录（从哪开始、卡在哪、怎么突破）
- **误判**：把"想学"当"在学"；把职业培训当学习偏好

### 11. 金钱与风险
- **问**：风险偏好？不确定性容忍度？花钱的逻辑是什么？
- **证据**：真实的花钱与冒险决策（T1）
- **误判**：把口头"我不在乎钱"当事实；把一次冲动消费当消费观

### 12. 身体与生活
- **问**：作息、饮食、运动、空间偏好？
- **证据**：重复出现的生活安排（T1）
- **误判**：把"想早睡"当早睡；把出差期的作息当常态

## 二、七级证据

按**信号强度**排序，不按"说得多用力"排序。**行为投票 > 口头声明**，这是全表第一原则。

| 等级 | 名称 | 判定标准 | 基线置信度 |
|---|---|---|---|
| **T1** | 高成本真实行为 | 付出钱/时间/机会成本，且重复（≥2 次） | **0.85** |
| **T2** | 真实决策 + 理由 | 真实场景做了选择，并说出取舍逻辑 | **0.78** |
| **T3** | 反复自述且一致 | 同一描述 ≥3 次、跨 ≥2 周、无矛盾 | **0.72** |
| **T4** | 单次明确自述 | 一次清晰陈述，无回避、无假设语气 | **0.60** |
| **T5** | 情绪强度反应 | 措辞突变、篇幅异常、反复绕回 | **0.50** |
| **T6** | 顺口提及/假设句/转述 | 未展开、假设情境、引用他人 | **0.30** |
| **T7** | AI 推断 | 跨条目归纳、类比、理论化 | **≤0.25** |

### 硬约束
- T6 不能单独升级到 L2/L3，只能作佐证。
- **弱信号合成**：≥3 条同向 T6、跨 ≥14 天 → 可合成一条 **T3 级证据**（0.72），但**仍须用户确认**才建页。三条 T6 不会自动变成结论，它只是终于够格被提出来。
- **T7 永远不参与合成。** 推断 + 推断 ≠ 证据，只会让错误互相印证。
- T5 情绪不能单独成页，必须找到 T1/T2 的行为落点；≥3 次同类情绪 **且** 有 1 次行为落点 → 按 T2 处理。
- T7 必须标 `「非原文·推断」`，上限 0.25。
- 多级证据支持时，`证据等级` 取最高级，但正文列全部来源。

## 三、两类自我

**你描述的你** 和 **你行动的你** 常常不是同一个人。

- **声明自我**：主要来自 T3 / T4
- **行为自我**：主要来自 T1 / T2

| 情况 | 处理 |
|---|---|
| 两者一致 | 置信度 **+0.08**，标 `双源一致` |
| 两者冲突 | **不进冲突队列**。两条独立成页，各标 `来源类型`，并在 `知识库 wiki/分析 analyses/自我认知偏差.md` 记一条对照 |

对照记录格式：

```markdown
## 偏差-0003：关于「是否需要他人认可」
- 声明自我：我不太在意别人怎么看（T3，0.72）→ [[不在意评价]]
- 行为自我：发完东西反复刷新，决策前先试探他人态度（T1，0.85）→ [[先试探再行动]]
- 可能解释（「非原文·推断」，0.25）：在意的是"被否定"而非"被看见"
- 待验证场景：下次出现"主动询问他人意见"时，记录当时的内心表述
```

**不要让 AI 判定哪个才是"真实的我"。** 它的职责是把差异摆上桌。

### 自我评价的生命周期

声明自我不能直接当结论用，它要先经过一道核验。所有自我评价（简历措辞、自述、MBTI/星座、转述他人评价）入场时都是 `待核假设`，进 `档案 profile/自我评价待核.md`：

```
待核 ──1 次 T1/T2 同向行为──→ 已证实（升 L2，取行为基线）
  ├──1 次 T1/T2 反向行为──→ 已证伪（保留原话 + 进 自我认知偏差）
  ├──只在特定条件下成立──→ 部分属实（改成"在 X 下 Y"）
  └──180 天无证据──→ 长期未核（降权、移出 me.md、不删）
```

三条硬约束：
- **待核内容不得进入** 说明书 / 声音 / 框架 / 分身——这四个产出面的每条都要有行为依据。
- **一条只需要一次证据就能定生死**，不要等三次，否则队列永远清不掉。
- **证伪不是删除。** 旧表述留下，因为它证明你曾经那样认为——这本身是数据。

## 四、时间轨迹

| 标签 | 定义 | 判据 |
|---|---|---|
| `结构性` | 长期稳定、跨场景一致 | 首次出现 ≥1 年且近 90 天仍有 T1/T2 |
| `稳定` | 当前有效，样本未跨年 | 近 90 天 ≥2 次证据 |
| `上升` | 频率或强度明显增加 | 近 60 天证据数 > 之前 60 天的 2 倍 |
| `衰退` | 曾经明显，近期减弱 | 近 90 天 ≤ 之前 90 天的 1/2 |
| `休眠` | 有历史证据，近 180 天无新证据 | 仅时间判定，不代表消失 |
| `周期性` | 按固定周期反复 | 至少观察 2 个完整周期 |

报告时必须带轨迹：**"你在 X 上有结构性倾向，最近证据是 2026-09"**，而不是"你有 X 特质"。

## 五、反例检索（落笔前的强制动作）

1. **相反表述**：搜含义相反的词
2. **相反决策**：找同类场景的不同选择
3. **缺席证据**：该出现却没出现——"你声称很在意，但半年零记录"本身就是证据

三种结果：
- 找到反例 → 写进 `反例与边界`，置信度 ×0.90
- 找到强反例 → 不写该条，或改写成条件式：`在 A 下 Y，在 B 下 Z`
- 未找到 → 写 `已检索 L1（YYYY-MM-DD 至 YYYY-MM-DD），暂未发现反例`。**不写检索范围＝没做。**

## 六、置信度与衰减

| 动作 | 影响 |
|---|---|
| 新条目按证据等级取基线 | 见上表 |
| 独立证据再次支持（强化） | +0.05，`强化次数 +1` |
| 双源一致 | +0.08 |
| 存在未化解反例 | ×0.90 |
| 跨 180 天无新证据 | 按衰减公式，<0.15 转休眠 |
| 用户明确否定 | 状态 `已推翻`，置信度 0，**保留页面**并记原话 |

**衰减（读时计算，不改写 frontmatter 基线）**：

```
半衰期 = 180 × (1 + ln(1 + 强化次数))   天
当前置信度 = 基线置信度 × 0.5 ^ (闲置天数 / 半衰期)
```

- `< 0.15` → `休眠`，移入归档，**永不硬删除**
- **检索不算强化**；只有用户确认、主动重述、接受引用才 +1
- 上限 **0.95**。没有 1.0——一个人对自己也达不到 1.0

**口语表达**：≥0.70 稳固 / 0.40–0.70 一般 / <0.40 待观察。

## 七、检索协议

顺序：`目录 index.md` → `me.md` → `L3` → `声音/框架` → `L2` → 必要时回 `sources/` 与 `raw/` 原文。

回答格式：
```
结论（一句话）
证据：[[条目]] · 2026-09-27 · 稳固 0.78
边界：在时间充裕时成立；紧急窗口下会临场拍板（2026-10-12 反例）
```

档案里没有 → 直说"档案里没有这块"，并问要不要现在记一条。**禁止**用常识补齐。
