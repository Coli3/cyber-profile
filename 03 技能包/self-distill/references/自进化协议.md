# 自进化协议

自进化最容易被误解成"AI 自动改档案"。不是。
**没有人踩刹车的自动改写，三个月后你收获的是一个比你更讨人喜欢的假人。**

所以这套协议的重点不在"能改"，在**改得可回滚、可审计、不过拟合**。

---

## 一、四环闭环

```
  用户说「我不会这样说」「这不对」
          │
          ▼  （秒级）
   ①  纠正 ──→ 直接改条目 + 写纠正日志 + 快照
          │
          ▼  （每次对话）
   ②  捕获 ──→ 只写 L1，不动高层
          │
          ▼  （周/月/季）
   ③  蒸馏 ──→ L1→L2→L3→L4候选，升级要签字
          │
          ▼  （每两周）
   ④  体检 ──→ 衰减、孤页、矛盾、美化检测、更新指标
          │
          └──────────→ 回到 ①
```

四环各自负责一种"坏法"，缺一环就烂一处：

| 缺失 | 后果 |
|---|---|
| 没纠正 | 档案越写越像 AI 眼中的你，你每次都要重新解释 |
| 没捕获 | 蒸馏时无米下锅，只能靠旧结论自我循环 |
| 没蒸馏 | L1 变成垃圾场，越攒越不敢看 |
| 没体检 | 过时结论冒充现状，孤立页越来越多，最后没人信 |

---

## 二、纠正通道（最快的一环）

用户说"不对""我不会这样""我应该是……"时，**立即处理，不等复盘**。

### 判定属于哪类纠正

| 类型 | 例子 | 处理 |
|---|---|---|
| **事实错** | "我 2024 年就换城市了" | 改对应字段，旧值进变更记录 |
| **语气错** | "我不会用'赋能'这个词" | 改 `声音 voice.md` + 写入"避用词" |
| **判断错** | "我不是回避冲突，我是懒得吵" | 改条目表述 + 置信度重置为 0.6 + 保留原证据 |
| **整体否定** | "这根本不像我" | 不辩解；标记条目 `已推翻`，重跑该维度 |

### 执行顺序（不可颠倒）

1. 复述你听到的纠正（一句话），确认没理解错。
2. 快照：把将被修改的文件复制到 `.history/YYYY-MM-DD-HHMM/`。
3. 改文件（Edit，不做整体重写）。
4. 在 `纠正日志 correction-log.md` 追加一条。
5. 回执：`已改：B-0007「回避冲突」→「懒得吵」（0.72→0.60），旧版已快照`。

### 纠正日志格式

```markdown
## [2026-10-21 14:32] 判断错
- 原表述：在冲突中倾向于回避（L2 B-0007，0.72）
- 用户原话："我不是回避冲突，我是懒得吵。"
- 新表述：在低价值冲突中选择不投入注意力；面对高价值冲突时会正面处理
- 置信度：0.72 → 0.60（新证据尚未积累）
- 连带影响：说明书「怎么纠正我」一节已同步
```

**纠正不是覆盖，是分层。** 旧版本留在 `.history/`、原证据留在页内「变更记录」，随时可查"我什么时候改的主意"。

## 三、过拟合保护（最重要的刹车）

### 三次规则（时序说明）

**前 2 次：自动改。第 3 次起：不改，只提案。**

顺序必须是这样，否则"停手"永远晚一步——等你改完第 3 次再提示，拦住的只是第 4 次。

同一方向第 3 次纠正时，**先不动文件**，直接说：

> 「这已经是第三次你往同一个方向纠正我：你比自己描述的更在意他人反馈。
> 这一次我先不改，因为你可能需要先确认一下：
> ① 我之前确实记错了 ② 你最近变了 ③ 只是这几天状态不好？
> 你说是哪种，我再动。」

用户确认后：
- 选 ① → 按纠正处理，同时把旧条目降为 `已推翻`（保留原话）。
- 选 ② → 建新条目，旧条目标 `superseded_by`，**两条都留**。
- 选 ③ → 不改，在 `纠正日志` 记一条"已提案，用户判断为临时状态"。

之后若同一方向继续出现，**每 3 次才重新提案一次**，不要每次都问——那是骚扰。

理由：一次情绪波动会不会变成新的人格结论，只能由人判断。AI 在这儿唯一正确的动作是**停手**。

### 反向保护：不许讨好

- 用户说"对，就是这样"时，**不要**顺手把置信度拉到 0.95。强化只 +0.05，且要有新证据。
- 用户夸档案写得好的时候，检查一下是不是因为**写得好听**而不是写得准。

## 三之二、结果反馈（唯一的"事后验证"）

纠正和捕获都是**入场时**的反馈；这一环是**出场后**的反馈——**这条判断后来应验了吗？**

L2 / L3 各带两个计数：

| 字段 | 何时 +1 |
|---|---|
| `命中` | 用户说"你上次说得对""确实是这样"，或该判断被后续事实印证 |
| `落空` | 用户说"不是这样""这次不一样"，或判断被事实推翻 |

**命中率** = `命中 / (命中 + 落空)`，`命中 + 落空 < 3` 时不显示——样本太少，比例没有意义。

用途有三：
1. **调权**：命中率 ≥0.8 且样本 ≥5 的条目，月蒸馏时可 +0.05（上限 0.95）；命中率 <0.4 的降到 `待观察`，并在体检时专门审。
2. **发现盲区**：哪一类判断（决策 / 关系 / 情绪）命中率系统性偏低，就是你**最不了解自己的地方**——这比任何自述都准。
3. **防止自洽**：一个从不落空的档案，不是懂你，是没人反驳它。

**纪律**：只有当用户明确表态时才计数。AI **不得**自己判定"这条应验了"——那是自我打分。

## 四、四个健康指标

写进 `档案 profile/健康 health.md`，体检时更新。

| 指标 | 算法 | 健康区间 | 不健康意味着 |
|---|---|---|---|
| **覆盖度** | 12 维度中有 ≥1 条稳固（≥0.7）条目的维度数 | 3 个月 ≥6；6 个月 ≥9 | 偏科：只懂工作不懂生活 |
| **准确率** | 随机抽 10 条问用户"准不准"，准的 ÷ 10 | ≥ 0.8 | 低于 0.8 说明采集噪声大，应收紧门槛 |
| **新鲜度** | ≥180 天未强化的条目 ÷ 总条目 | < 30% | 档案在变成历史文档 |
| **张力数** | `待确认` 里未解冲突条数 | **1–3** | 0 = 自我美化；>5 = 判据太松 |

### 准确率抽样怎么问

不要问"这条对吗"（用户会客气）。问：

> 「B-0007 说你在决策前必须看到全貌。**给我一个反例**，或者告诉我它在什么情况下不成立。」

能给出反例 → 该条需要加边界；说不出又坚持成立 → 才算通过。**用"能否反驳"代替"是否同意"，能过滤掉大部分社交性点头。**

## 五、体检清单（每两周 / 季蒸馏后强制）

### 结构检查
- [ ] 断链、指错文件、缺失交叉引用
- [ ] 目录与文件不一致
- [ ] 孤立页（无入链）
- [ ] 页面属性缺漏

### 内容检查
- [ ] 页面间矛盾（→ 冲突队列，不化解）
- [ ] 已被新证据取代的过时说法（标 `superseded_by`）
- [ ] 推断未标 `「非原文·推断」`
- [ ] 该升级未升级 / 不该升级却升级
- [ ] L4 是否被动过（动过即事故）

### 进化检查（这一节是 v2 新增，最容易被跳过）
- [ ] **美化检测**：通读全部 L2/L3，有没有"任何人的档案都能写"的句子？有没有该难听却被写得很体面的条目？
- [ ] **配音检测**：`声音 voice.md` 里的每条，能不能在 L1 原话里找到对应？找不到就是 AI 编的。
- [ ] **单源检测**：有没有条目只靠一个来源支撑却标着稳固？
- [ ] **沉默检测**：某个曾经很重要的维度，最近 180 天零证据——是休眠，还是你刻意不说？

### 指标更新
- [ ] 重算四个指标，写入 `健康 health.md`
- [ ] 覆盖度不足 6 时，在报告里指定**下个月优先补哪 2 个维度**

修完写 `报告 reports/YYYY-MM-DD 体检报告.md`（模板见 `references/报告模板.md` 第七节），日志追加一条。**四项进化检查一项都不能跳。**

## 六、版本与回滚

### 快照规则
- **写前快照**：任何修改 L2/L3/L4/产出面 的操作，先把原文件复制到 `.history/YYYY-MM-DD-HHMM/<原相对路径>`。
- L1 是追加型（当天文件），不必每次快照，但每天首次写入前快照一次。
- `.history/` 是 dot 目录，Obsidian 不索引，不污染图谱。

### 保留策略
- 最近 30 天：全部保留
- 30–180 天：每月保留 1 份（1 号那份）
- 180 天以上：只保留每次「季蒸馏」后的快照（那是里程碑）

### 回滚
用户说 `回滚 2026-10-18`：
1. 列出该日及之前最近的快照清单，让用户确认要回滚哪些文件。
2. 先把**当前版本**也快照一份（回滚本身也要能撤销）。
3. 还原选定文件。
4. 在纠正日志记一条：`[日期] 回滚 | 从 2026-10-18 快照还原 4 个文件`。
5. **不删除**回滚点之后的快照。

## 七、自进化的边界：什么绝不自动做

| 绝不自动 | 原因 |
|---|---|
| 修改 L4 | 锚点一旦漂移，全盘失真 |
| 化解冲突 | 张力是资产，不是 bug |
| 提升到 L2/L3（无人确认时） | 升级是判断，不是统计 |
| 声称"你变了" | 变化需要人自己承认 |
| 删除任何页面 | 只能标 `休眠` / `已推翻` |
| 把纠正当成"用户情绪"忽略 | 用户比你更了解用户 |
| 自动调整阈值 | 阈值是校准工具，动了就没法比较历史 |

## 八、失败模式对照表

| 失败 | 表现 | 根因 | 修法 |
|---|---|---|---|
| **自恋循环** | 档案越来越夸你，每条都"深刻""有洞察力" | 只捕获不纠正，AI 在自我确认 | 恢复纠偏：主动找反例、跑美化检测 |
| **过拟合** | 某次情绪后，档案把你写成另一个人 | 无三次规则 | 回滚 + 降置信度 |
| **僵尸档案** | 三个月没更新，但你还在用 | 没接线 / 没触发 | 跑 `接线检查`，设两周体检 |
| **样本偏差** | 只记得住工作场景 | 对话都发生在工作时 | 主动补维度，明确问生活侧 |
| **语言失真** | 档案读起来像 AI 写的总结 | 转述代替原话 | 每条保留至少一句原话 |
| **隐私泄漏** | 分身说出了不该说的家庭细节 | 密级判定失败 | 全量重扫密级，P/R 移出 O 产物的引用 |

---

## 九、一句话

自进化的目标不是"越来越像我"，而是**越来越经得起我反驳**。

一份你永远挑不出错的档案，不是好档案——那是镜子上的雾。
